# Потапенко: побег

3D-игра в браузере с видом сверху. В лобби есть коллекция из 18 бойцов с фотографиями из присланной папки. Кейс за 120 шумиликов открывает нового бойца. У каждого героя своя способность; у Шумыча — электросамокат на 5 секунд. Бойцов можно улучшать в лобби и во время забега.

Есть регистрация и вход: сохранения аккаунта лежат в `.local/users.json` рядом с сервером и переживают перезапуск браузера и игры. Аккаунт администратора: логин `owner`, пароль `0675097117`. В панели owner можно банить и разбанивать игроков, менять баланс, выдавать персонажей. Сервер слушает только локальное устройство.

Выбери режим «Уровни» или «Аркада». В аркаде нужно выжить 60 секунд, а босс постепенно ускоряется. Улучшения крутят колесо и добавляют соответствующий бонус к скорости, защите от столкновения, монетам или способности.

Серверная часть написана на Python и использует только стандартную библиотеку. Сцена Three.js подгружается с CDN, поэтому для игры требуется интернет-соединение.

## Запуск

1. Установи Python 3, если он ещё не установлен.
2. Запусти `python app.py` из этой папки.
3. Открой в браузере `http://localhost:8000`.

Управление: WASD или стрелки для движения, E — способность. Для телефона открой ⚙ и выбери «Телефон» — появятся стик и кнопка способности.

Монеты, рекорд, громкость и открытые уровни сохраняются в браузере на этом устройстве.
